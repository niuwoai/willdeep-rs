# Short Drama Studio · writing guides

These are the per-stage guides the plugin page and `drama.get_stage_context`
use. Normally you do not read them directly: `drama.get_stage_context` returns
the right guide (plus the compliance red lines and the user's chosen genre
add-ons) in its `system` text, already edited the way the user saved them in
the plugin's skill settings. Read a file here only to look something up.

| File | Stage |
| --- | --- |
| `planning.md` | Drama plan: logline, conflict, arc, episode count |
| `character.md` | Character identity and visual anchors |
| `assets.md` | Appearances, scenes, scene variants, props, voices |
| `episode.md`, `episodes-batch.md` | Episode scripts, one or many at once |
| `passage.md` | Rewriting a selected passage |
| `storyboard.md` | Shots: story beat, dialogue, camera, captions, duration |
| `frames.md` | Start / end frame descriptions |
| `review.md` | Content review |
| `panel.md` | Expert panel (aspect `panel`): six seats and a chair that review the series framework or one script |
| `image-qa.md` | Candidate image QA |
| `compliance.md` | Content red lines — always applies |
| `common/romance.md`, `common/time-travel.md`, `common/de-ai-flavor.md` | Genre and style add-ons |
