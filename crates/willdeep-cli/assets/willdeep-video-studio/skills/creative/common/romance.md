# 言情

叠加在其它技能之上，管感情线怎么写。

## 拉扯要有理由

两个人靠近或推开，每一次都要有具体的理由，而且理由要是「他们自己也没法轻易解决的」。

- 好的阻力来自处境和性格：她要养家所以不能冒险，他不信人所以不肯开口。
- 差的阻力来自误会和巧合：撞见了、听错了、手机没电。用一次可以，用两次观众就不信了。
- 阻力被解决之后必须换一个新的。同一个阻力反复挡三次，感情线就停在原地。

## 进展的节奏

短剧里感情线的推进要**具体到动作**，不是心理描写。

台阶大致是：注意到 → 在意 → 试探 → 靠近 → 退回 → 确认。每一档都要有一个可拍的动作作为标记：

- 「在意」的标记可以是他记住了她不吃香菜。
- 「试探」的标记可以是她把伞往他那边偏了两寸。
- 「退回」的标记可以是他松开了已经握住的手。

不要跳台阶。跳过去的那一档观众感觉不到，后面的深情就没有依据。

## 亲密的分寸

- 靠近的动作比亲密的动作有效。递东西时手指碰到、替他挡了一下、站在他侧后半步，这些比拥抱更让人记得。
- 关键的亲密动作全剧不要超过两三次，用多了不值钱。
- 拒绝和退让也是感情线。一直进展的感情线是平的。

## 两个人要不一样

写之前看角色表：如果两个人的说话方式差不多，感情戏会像一个人在自言自语。主动让他们的节奏错开——一个话多一个话少，一个直接一个绕。

## 避免

- 不要写「他的心跳漏了一拍」这类身体反应清单。
- 不要用旁白解释他们的感情进展到哪一步，让动作说。
- 不要让感情线独立于主线。它应该和主角的困境互相影响：因为爱她所以不能用金手指，或者因为用了金手指所以失去她。
