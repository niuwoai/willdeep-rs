- 每项「已到位」至少对应一条事件级测试；改动行为时同步改测试。
- 整轮回放测试：喂一段真实的 Runtime 事件流（`~/.willdeep/runtime/events.ndjson` 脱敏片段），断言最终聊天区行序与状态。
- Web 列的 4、5、6、7、8 项已于 rc15 至 rc18 到位；两端剩第 11（检查点回退）、16（零配置首次使用）、18（工具行回放）三项。
