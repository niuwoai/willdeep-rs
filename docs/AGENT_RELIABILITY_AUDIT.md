## 本次审计排除的误报

- 规则加载器拒绝绝对路径与文件工具 `validate_workspace_relative` 一致，不存在“工具允许写入绝对路径但规则遗漏”的证据。
- 手工压缩的累计账目与普通运行检查点分开；再次保存和继续执行不会把已保存压缩账目重新算作下一轮消耗。账目仅代表 Provider 已报告的用量。
- Gitlink 原来仅凭 HEAD 的不足已在 rc45 修复；不能再把该旧实现当作当前未修复问题。
- 默认忽略的子进程辅助入口与未执行的外部测试必须分开统计；辅助入口可能由父用例实际运行，外部测试不可据此声称通过。
